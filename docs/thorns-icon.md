# Ícone de espinhos

Arquivo final: `assets/interface/thorns_icon.png`.

Gerado com a ferramenta integrada **ImageGen**, com transparência, e copiado para o projeto sem substituir os três ícones originais. Referências de estilo: `hearth_icon.png`, `shield_icon.png` e `poison_icon.png`, em `assets/interface/`. O mesmo ícone é usado no HUD e na carta Espinhos; o modo difícil continua ocultando ilustrações nas cartas.

Prompt final utilizado:

```text
Use case: stylized-concept. Asset type: single small status-effect icon for the Godot game Incógnita Deck, to appear beside the supplied heart, shield and poison icons. Input images are STYLE REFERENCES only, not edit targets. Create a single THORNS / retaliation icon: a simple compact loop of brown thorny vine with 5 to 7 clearly visible sharp triangular thorns, muted sage-green tiny accent leaves at most two, thick slightly imperfect black ink outline, flat colored fills with only one simple highlight/shadow matching the provided shield and potion. Centered silhouette, very easy to read at 40 x 40 pixels. Match the charming school notebook doodle / cartoon style of the references, not realistic, not 3D. Entire object fully in frame with narrow even transparent margins (roughly 10 percent each side). True transparent background and alpha, no paper texture, no badge/container, no lettering, no numbers, no text, no watermark. Deliver one isolated square PNG icon.
```
